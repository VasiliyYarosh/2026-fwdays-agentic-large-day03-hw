# Spec: Drawing cursor occasionally turns white (hard to see)

**Issue:** [excalidraw/excalidraw#11074](https://github.com/excalidraw/excalidraw/issues/11074)
**SDD Approach:** Simple Markdown
**Complexity:** Low
**Blast Radius:** Low

## Problem

The draw/freedraw tool (and all other shape tools) uses the browser's native `crosshair` cursor via `CURSOR_TYPE.CROSSHAIR`. In dark mode, the interactive canvas has a CSS filter `invert(93%) hue-rotate(180deg)` applied (defined in `theme.scss`, applied in `styles.scss`). This filter inverts the native black crosshair cursor to near-white, making it invisible against the (also inverted, light-appearing) canvas background.

Switching to another tool (e.g., line) and back temporarily resets the cursor, but the issue recurs after a few strokes because the cursor state is re-applied from the same `CURSOR_TYPE.CROSSHAIR` value.

### Root Cause

1. `setCursorForShape()` in `cursor.ts` sets `CURSOR_TYPE.CROSSHAIR` (native browser cursor) for all shape tools
2. Native `crosshair` cursor is black
3. Dark mode CSS filter `invert(93%) hue-rotate(180deg)` on `.interactive` canvas inverts it to near-white
4. Near-white cursor on light-appearing (inverted) canvas background = invisible

### Prior Art

- **Eraser cursor** (`setEraserCursor()`) — canvas-drawn circle with theme-aware colors, cached by theme
- **Laser pointer cursor** — SVG-based with separate light/dark mode data URLs
- **PR #7132** — "Better laser cursor for dark mode" solved the same class of problem for the laser tool

## Solution

Create a custom theme-aware crosshair cursor using an offscreen canvas (same pattern as `setEraserCursor()`):

1. Add `setCrosshairCursor(interactiveCanvas, theme)` function in `cursor.ts`
   - Draw a "+" crosshair shape on a 20×20 offscreen canvas
   - Light mode: black lines (`#000`) on transparent background
   - Dark mode: white lines (`#fff`) on transparent — the CSS `invert(93%)` filter will invert them to dark, making the cursor visible
   - Cache by theme (invalidate when theme changes)
   - Set as CSS cursor via data URL with hotspot at center (10, 10)

2. Replace `CURSOR_TYPE.CROSSHAIR` usage in `setCursorForShape()` with `setCrosshairCursor()` call
